## 1. 风控两阶段

```text
订单提交前 pre_check          订单成交后 post_check
┌─────────────────────┐      ┌─────────────────────┐
│ 熔断检查             │      │ 仓位更新             │
│ 结算状态检查         │      │ 暴露重算             │
│ 亏损检查             │      │ 硬限制复核           │
│ 仓位检查             │      └─────────────────────┘
└─────────────────────┘
```

- **pre_check**：下单入口强制调用，未通过则拒单。
- **post_check**：成交后更新仓位。
  - Buy：`quantity += qty`，`notional += value`
  - Sell：`quantity -= qty`

## 2. 硬限制与熔断

| 机制 | 参数/说明 |
|------|----------|
| 仓位硬限制 | 单市场 / 总仓位上限 |
| 时间窗口 | 2 小时窗口内限制下单频率/金额 |
| 3 级熔断 | 分级触发，最高级停止交易 |
| UMA 争议 | 争议中市场禁入 |
| Gas 保护 | gas 异常时拦截 |

## 3. 下单金额上限（OrderSizeLimits）

按总资产五档动态调整，每单 $1 ~ $100。

## 4. 仓位来源一致性

- 本地仓位：RiskEngine
- 远程仓位：Polymarket `/data/positions`
- 两者由 StateSync 统一对账（reconcile_positions），数量差异 / missing remote 分级告警。

## 5. 关键约束

- 任何 AI 不得自行关闭 Risk Gate（Human 把关）。
- 成交后风险状态必须由真实 fill 驱动更新，禁止凭空估算。
